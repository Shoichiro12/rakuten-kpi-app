## アプリUIの規則（docs_ui_design_knowledge / docs_ui_number_and_chart_rules より）

- 強調は1画面に1つ。大きい数字は多くて2つ。他はグレーで沈める
- アクセント色は1〜2色。状態色（良い/注意/危険/重大）は予約語で、装飾に流用しない。色だけで意味を伝えない
- 金額は「万・億」で丸める（`1,234.5万円`）。`¥12.3M` は使わない
- 前期比: CVR/CTR/ROAS/ROI/GPR は「ポイント」。CPC/CPO/広告費は「下がったら緑」
- 目標進捗は弾丸グラフ。二軸チャートは作らない。表は縞々にしない
- 空・読込中・エラーの状態を設計する。「データがありません」で画面を消さない
- 採らないもの: ダークテーマ、ネオン・グラデーション背景

## LPの規則（docs_LP_lowya_dna / hallmark_audit / design_review より）

- C案トークン: ink #383731 / paper #fdfcf9 / bg-alt #f4f1ea / sage #78927b（装飾のみ、単独テキスト不可）/ sage-deep #4c6850 / alert #c2382f / up #17714d
- 見出しは角ゴシック主役（2026-08-20決定）。ワードマーク「ウレシル.」だけ丸ゴシック
- 暗色地の `:focus-visible` は紙色に反転
- **捏造禁止**: 導入社数、○倍速い、架空の声は書かない。載せられる事実だけ。事例はオーナーが許諾済みの内容を提供するまでHTMLコメントで場所を確保
- 価格は税込を主表記から外さない（税抜・税込を同じ視認性で並列）
