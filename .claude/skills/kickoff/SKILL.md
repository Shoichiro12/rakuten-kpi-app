# セッション開始（/kickoff）

1. `git status --short` と `git log --oneline -5` を実行し、未コミット・直近コミットを把握する
2. `pmo` サブエージェントに「申し送り台帳の未実装・未実施を一覧にして」と依頼する
3. 最新の `docs/作業報告_*.md` の「残作業」節を読む
4. `security/index.md`（またはプロジェクト側 security_index.md）の最終実施日を確認し、7日以上空いていれば `/security-check` を提案する
5. 以上を「未コミット / 未実装の決定 / 残作業 / 今日の提案」の4項目で短く返し、オーナーの指示を待つ

推測で埋めない。ファイルが無ければ「無い」と書く。
