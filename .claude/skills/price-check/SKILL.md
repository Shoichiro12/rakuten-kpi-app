# 価格・法的文面の整合チェック（/price-check）

1. `legal-finance` サブエージェントに「アプリ・LP・Stripe の3箇所の価格整合と、法的文面の整合を確認して」と依頼する
2. 食い違いがあれば `developer`（アプリ・LP側）に修正させ、Stripe側の変更はオーナーへの手順として渡す
3. 税率を変えた場合は「既存契約には遡って適用されない」ことを明記し、契約の作り直しが要るかを判断してもらう
4. `pmo` に台帳を更新させ、「専門家確認が必要」な論点があれば台帳の該当行に追記する

出力の最後に必ず「法的助言ではなく専門家の確認が必要」と書く。
