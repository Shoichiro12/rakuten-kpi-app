- `cd frontend && npm install`（node_modules未展開だったため）→ `npm run build` 型エラー0。
- バックエンドも `pip install -r requirements.txt` → `python3 -c "from main import app"` import OK
  （バックエンド自体は無変更。dist配信のE2Eに必要なため準備）。
- `npm run build` で `frontend/dist` を生成し、backendのSPA配信（`main.py` の `_serve_spa`）経由で
  ローカルuvicorn（127.0.0.1:8000）から配信。`POST /api/sample-data` でサンプルデータ投入。
- puppeteer-core（スクラッチパッドに一時インストール）で、このセッションに同梱されている
  Chromium（`/opt/pw-browsers/chromium-1194`）をheadless駆動し、実ブラウザで一連の操作を実測:
  1. **カテゴリマスタ**: 「全選択」チェックボックスで5件すべてチェック → 解除 → 1件だけ選択 →
     「選択した1件を削除」ボタン表示 → クリックで確認ダイアログ（タイトル・本文文言とも意図どおり）
     → チェックボックス必須の確認 → 削除実行 → フラッシュメッセージ
     「1件のカテゴリを削除しました（4商品を未分類化）」→ 一覧が5件→4件に減少
  2. **商品マスタ**: 2行を個別選択 → 「選択した2件を削除」（正しい件数）→ ヘッダー
     「このページを全選択」クリックで全12件に追従（「選択した12件を削除」）→ 再クリックで
     解除するとボタンごと非表示に戻る（0件のとき表示しない仕様どおり）→ 2件を選び直して
     一括削除実行 → 確認ダイアログの本文文言確認 → 削除実行 → フラッシュメッセージ
     「2件の商品を削除しました」→ 一覧が12件→10件に減少 → ヘッダーチェックボックスが
     未選択状態に戻る（選択状態が正しくクリアされている）
  3. コンソールエラーは `fonts.googleapis.com` への `ERR_CONNECTION_RESET`
     （このサンドボックス環境の既知のネットワーク制約。別ページの単独チェックで確認済みで
     アプリのコードとは無関係）のみ。機能起因のエラーは0件。
