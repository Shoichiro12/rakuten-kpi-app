# 軍令候補（巡回で見つけたもの）

夜勤の「巡回」フェーズ（`.claude/commands/yakin.md` 参照）が毎晩コード・ドキュメント・
CLAUDE.md申し送り台帳を見回って発見した問題の記録。**発見のみで、修正はしない。**

候補の扱い:
- 昇格（`docs/office_map.html` QUESTS の急務 `stamp:"wait"` に格上げ）・却下は**オーナーのみ**が行う
- 夜勤は候補の札（`stamp:"kouho"`）に手を出さない。昇格も却下も自分ではしない
- 1晩あたり新規3件まで。既存の軍令（QUESTSの急務・後日）・候補（このファイル）・
  台帳（CLAUDE.md）記載と重複するものは挙げない
- 巡回は新しい候補を書く前に、必ず本ファイルの「却下済み」節と照合し、
  一度却下されたものを再提案しない
