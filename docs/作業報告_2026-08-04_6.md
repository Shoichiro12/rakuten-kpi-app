## 1. 月額表示を触らなかった理由（3つあります）

**① バックエンド由来で、フロントでは統一できません**

`Billing.tsx:262` は `plan?.price_label` をそのまま表示しているだけで、値は
`backend/billing.py` の `PLAN_AMOUNT_LABEL` が作っています。**しかも env で上書き可能**です。

```python
PLAN_AMOUNT_LABEL = os.environ.get(
    "PLAN_AMOUNT_LABEL", "¥20,000（税抜） / ¥22,000（税込）"
)
```

フロントで整形しても、env を変えられたら表記が崩れます。サーバーが完成した文字列を返す
今の設計は理にかなっているので、フロント側で加工しないのが正しいと判断しました。

**② 法令上の制約がコードに明記されています**

`billing.py` の直前のコメントです。

```
# ⚠️ 総額表示義務（消費税転嫁対策特別措置法の失効後、税込の総額表示が義務）のため、
#    税込金額を主表記から外さないこと。税抜だけの表示にしない。
#    税抜・税込は並列で、同じ視認性で見せる。
```

書式を変える作業とはいえ、ここに手を入れるのは避けるべき領域です。

**③ 契約金額に「万・億」の丸めを当ててはいけません**

規則の丸めは **「カードと軸のみ。表・ツールチップ・CSVは生値」**（規則260行）です。
請求画面の金額は「正確な値を確認する場所」なので、`¥22,000` を `2.2万円` にするのは不適切です。

## 2. 診断パネルは `¥` 前置を残しました

`formatYen`（「円」後置・万億で丸め）を使うと `22,000円` になりますが、
**同じ画面の主表記である月額が `¥22,000` なので、ここだけ後置にすると画面内で
金額の書き方が食い違います。**

実画面を見ると、この画面の金額はすべて `¥` 前置で揃っています。

- 月額（バックエンド由来）: `¥20,000（税抜） / ¥22,000（税込）`
- 診断メッセージ（バックエンド由来）: `金額は ¥22,000（税込）です。`
- コンサル料金（静的テキスト）: `¥150,000〜`

そこで **`¥` は文言として残し、桁区切りだけ `formatCount` に寄せました。**
表示は1文字も変わりませんが、`toLocaleString` の直呼びが消え、書式処理が `format.ts` に集約されます。

### アカウント設定は実画面で出せませんでした

**ローカル（認証無効）ではアカウント設定は画面全体が
「ローカル開発モード（認証無効）のため、アカウント設定は利用できません」になります。**
`total_rows` の表示部分に到達できないため、代わりに vite 経由で `format.ts` を import して
関数単位で確認しました。

| 入力 | 変更前 `n.toLocaleString() + ' 行'` | 変更後 `formatCount(n, ' 行')` |
|---|---|---|
| 0 | `0 行` | `0 行` |
| 1 | `1 行` | `1 行` |
| 244 | `244 行` | `244 行` |
| 1,000 | `1,000 行` | `1,000 行` |
| 22,000 | `22,000 行` | `22,000 行` |
| 1,234,567 | `1,234,567 行` | `1,234,567 行` |
| 40,000,000 | `40,000,000 行` | `40,000,000 行` |

**7ケース全件一致**（`allMatch: true`）。診断パネルの金額も `¥22,000` で一致。

**改善が1つあります**: `null` / `undefined` / `NaN` のとき、**変更前は例外になっていましたが
`—` を返すようになりました。** `total_rows` が欠けた応答でも画面が壊れません。

本番（認証あり）では実画面で「登録データ N 行」が見えるので、デプロイ後にご確認ください。

## 4. 別チケットに切り出した論点: 金額書式が2系統あります

洗い出しの副産物です。**アプリ全体で金額の書き方が2つに分かれています。**

| 関数 | 表記 | 使用ファイル |
|---|---|---|
| `formatCurrency`（`lib/utils.ts`） | **`¥` 前置**・丸めなし | 9ファイル（GAP分析・商品別KPI・RPP・ダッシュボード等） |
| `formatYen`（`lib/format.ts`） | **`円` 後置**・万・億で丸める | 6ファイル（データ取込み・ジャンルカード等） |

**`Dashboard.tsx` と `RppAnalysis.tsx` は両方を使っています。**

規則52行は「セルの `¥` は消して見出しに（円）」なので、筋としては `format.ts` 側に寄せるべきです。
ただし表示が広範囲に変わるため区切り5より大きい作業になります。
**「区切り5は最小で閉じる」というご判断に沿って、統一は別チケットとして記録しました**
（CLAUDE.md 申し送り・計画書6章の両方に残してあります）。
