## 4. 見つけた問題と事故（時系列）

### ① LPのソースがどこにも存在しなかった（影響: 大・回収済み）

`ureshiru.vercel.app` は過去セッションで生成後にVercelへ直接アップロードされただけで、
GitHubにもローカルにも無かった。デプロイ済みファイルだけが唯一の正で、消えたら復元不能だった。
ライブから回収し `lp/` でgit管理化。可視テキスト1,627文字がライブと完全一致することを確認した。

### ② LPの内容が実装と食い違っていた（影響: 大・修正済み）

価格 ¥19,800（実際の請求は¥22,000）、廃止済みコンサルプラン¥100,000がプランカードとして
掲載、事業者名 JuneOne（アプリ・Stripe登録は中村祥一郎）。Stripe審査担当者が見るサイトで
表示価格と請求額が違う状態だった。全て修正し、返金文言は特商法と利用規約で文字単位一致。

### ③ Vercel Root Directory の保存空振りでLPが数分404（影響: 中・私のミス）

Git連携時に Root Directory=lp のSaveが空振りしたまま本番デプロイし、空のデプロイで
LPが404になった。設定を入れ直して復旧。この件も含めVercelの規約問題（Hobbyは商用不可）が
あったため、最終的にCloudflare Pagesへ移行して解消。

### ④ ユーザー入力の `pk_live_` 取り違えを検出（影響: 大・未然に防止）

`STRIPE_SECRET_KEY` に公開可能キー（`pk_live_`）が入っていた。サーバー認証には
シークレットキー（`sk_live_`）が必要で、そのままでは本番のStripe呼び出しが全滅していた。
Renderへ正しい鍵を投入後、本番診断で `key_livemode: true`・`ok: true` を確認。

### ⑤ ローカル `.env` に本番値が混入 → テスト用へ復旧確認済み

一時的にローカルが本番Price・税率を指していた。現在は `sk_test` / テストPrice / テスト税率に
戻っていることを確認。**原則: ローカル=テストモード、Render=本番モード。**
